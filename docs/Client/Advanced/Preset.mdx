# Preset

This section explains preset fields, purposes, allowed values, and behavior, with a complete example.

For `dc` format conventions, please read:
- [Getting Started](../Getting_Started)

## Location
- Directory: `DLC/preset/`
- Preset identifier is `[basic].identifier`. DisplayName only affects display text.

## Complete Example
```dc
[basic]
identifier = "performance"
alarm = false

[DisplayName]
zh_cn = "优化预设"
en_us = "Performance Preset"

[tip]
zh_cn = "适合低配机器"
en_us = "Recommended for low-end PCs"

[dependencies]
"Mod1"
"Mod2"

[conflicts]
"Mod3"
```

---

## Field Reference

#### `[basic].identifier`
- **Purpose**: Preset identifier used by dependencies/conflicts and runtime state.
- **Allowed**: Non-empty string.
- **Compatibility**: Missing identifier is migrated from the file name on load.

#### `[basic].alarm`
- **Purpose**: Whether enabling this preset shows alarm confirmation first.
- **Allowed**: Boolean.
- **Compatibility**: Legacy root `alarm` is still read and migrated into `[basic]`.

#### `[DisplayName]`
- **Purpose**: Preset display name.
- **Allowed**: Object `{ zh_cn: "...", en_us: "..." }`.
- **Fallback**: If empty, uses the file name (without extension).

#### `[tip]`
- **Purpose**: Preset tooltip text.
- **Allowed**: Object `{ zh_cn: "...", en_us: "..." }`.

#### `[dependencies]`
- **Purpose**: DLC or preset identifiers enabled by this preset.
- **Allowed**: Bare quoted strings in the table.
- **Compatibility**: Legacy root `enable = [...]` is still read and migrated to this table.

#### `[conflicts]`
- **Purpose**: DLC or preset identifiers that conflict with this preset.
- **Allowed**: Bare quoted strings in the table.
- **Compatibility**: Legacy root `conflicts = [...]` is still read and migrated to this table.

---

## State & Storage
- Stored at: `config/dlc_manager/state.dc`, field `presets`.
- Status values: `On` / `Part` / `Off`.

## Behavior
- When enabled, the preset attempts to enable all DLCs or presets in `[dependencies]`.
- DLCs or presets listed in `[conflicts]` are auto-disabled and show conflict warnings.
- Conflict handling supports cascade disable for dependents.
