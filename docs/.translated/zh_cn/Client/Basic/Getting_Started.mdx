# 开始使用（Getting Started）

本节介绍 DLC Manager 的核心能力与目录结构，并说明配置文件格式（JSON5）的通用约定。

## 介绍
DLC Manager 允许整合包开发者通过配置文件管理模组、资源包、数据包等内容的启用、下载与更新，并提供预设、公告、跳转等功能。本文档面向整合包开发者，使用正式说明与可直接上手的示例。

## 目录结构
建议在整合包根目录放置一个 `DLC/` 目录（可在配置中修改）：

```
DLC/
  remote/               # 远程 DLC 配置（可自动下载）
  required/             # 必要资源配置（强制/必需）
  preset/               # 预设配置
  info/                 # 信息文件（自动或手动维护）
  update/               # 更新包目录
  remote/redirect/      # 跳转配置（可选，不自动创建）
```

## 配置文件格式（JSON5）
- 默认使用 `.json5` 作为配置扩展名。
- 键名大小写不敏感（如 `DisplayName` 与 `displayname` 等效）。
- JSON5 支持注释、尾逗号、单引号；不支持反引号字符串。
- 多行文本推荐使用 `\n`，或使用字符串拼接/数组（详见公告与提示章节）。

## 快速上手（基础功能）
1) 在整合包根目录创建 `DLC/`（或在配置中指定 `dlcRoot`）。
2) 将模组文件**直接拖入** `DLC/` 目录。
3) 进入游戏，打开 DLC 管理器进行应用与管理。

## 关键概念
- **dlc_identifier / identifier**：用于逻辑关联与前置判断的核心标识符，建议保持稳定。
- **file_name**：实际文件名（用于查找/应用），可与展示名称不同。
- **DisplayName / tip**：多语言展示文本。
- **appliedTarget**：目标目录（如 `mods`、`resourcepacks`、`datapacks`、`tacz`），决定文件应用位置。

## 常见问题
- **为什么配置不生效？**
  - 确认扩展名为 `.json5`。
  - 确认配置位于正确目录（`DLC/remote`、`DLC/required` 等）。
  - 确认 `dlc_identifier/identifier` 不为空。
- **为什么显示名称不是我写的？**
  - DisplayName 未配置或语言未匹配时会回退为文件名。

> 若需更深入的配置说明，请继续阅读 Basic 与 Advanced 各章节。
