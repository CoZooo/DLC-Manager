# Info 文件（info）

本节说明 info 文件字段、用途、可填写值与回退规则，并给出完整示例。

`dc` 格式请先阅读：
- [开始使用](../Getting_Started)

## 位置
- 目录：`DLC/info/`
- 文件：`<name>.dc`

## 写入规则
- 基础用法：
  - 每个 DLC 对应一个 info 文件；配置名通常与 `file_name` 对应。
- Remote 下载与 Required 资源：
  - info 由系统自动生成，内容来自 remote/required 配置。
  - 若你手动维护 info，手动值优先。

## 完整示例
```dc
[basic]
identifier = "ExampleMod"
type = "mod"
file_name = "example-mod-1.0.0.jar"
RedirectUrl = "https://example.com/project-page"
isInList = true
isHidden = false
AllowEnableByAll = true
dependencies = ""
conflicts = ""
alarm = false

[DisplayName]
zh_cn = "示例模组"
en_us = "Example Mod"

[tip]
zh_cn = "这是一个示例说明"
en_us = "Example description"
```

---

## 字段说明

#### `file_name`
- **用途**：DLC 文件名（包含扩展名）。
- **可填**：字符串。

#### `identifier`
- **用途**：逻辑标识（前置/冲突/预设匹配）。
- **可填**：字符串。

#### `RedirectUrl`
- **用途**：在 DLC 列表中双击 DLC 名称时打开的链接。
- **可填**：字符串。

#### `[DisplayName]`
- **用途**：多语言显示名称。
- **可填**：对象 `{ zh_cn: "...", en_us: "..." }`。

#### `type`
- **用途**：分类类型。
- **可填**：`mod` / `resourcepack` / `datapack` / `gunpack` / `others`。

#### `isInList`
- **用途**：是否在 DLC 列表显示。
- **可填**：布尔。

#### `isHidden`
- **用途**：隐藏条目。通常用于前置库；无DLC依赖时会自动关闭。
- **可填**：布尔。

#### `AllowEnableByAll`
- **用途**：是否遵循“全部开启”而开启。
- **可填**：布尔。

#### `alarm`
- **用途**：开启前是否显示警告确认页。
- **可填**：布尔。

#### `dependencies`
- **用途**：前置 identifier 列表（字符串或数组）。

1) 字符串（逗号分隔）
```dc
"LibA, LibB"
```

2) 数组
```dc
["LibA", "LibB"]
```

#### `conflicts`
- **用途**：冲突 identifier 列表（字符串或数组，写法与 `dependencies` 相同）。

#### `[tip]`
- **用途**：多语言提示文本。
- **可填**：对象 `{ zh_cn: "...", en_us: "..." }`。

---

## 补充说明
- info 可自动生成，也可手动维护。
- 若 `DisplayName` 或 `tip` 缺失，会回退到 `file_name` 或 `identifier`。
