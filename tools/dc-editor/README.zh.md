# DC Editor

[English](README.md)

为 DLC Manager 创建和编辑 `.dc` 配置。可以通过表单填写内容，也可以直接编辑文本，并在导出前查看检查结果。

## 功能

- 创建内容说明、远程下载、必要资源、预设、公告、跳转、更新、版本、主配置和拓展包配置。
- 在表单和文本视图之间切换。
- 同时打开多份配置，切换文件并分别编辑。
- 预览公告内容，查看需要补全或修正的项目。
- 导出当前配置，或将多份配置一起导出为压缩包。
- 切换中文和英文界面。

## 开始使用

使用项目发布说明提供的网页入口，或从 [Releases](https://github.com/CoZooo/DLC-Manager/releases) 获取已经提供的桌面版。不同版本的下载方式以发布说明为准。

1. 选择要创建的配置类型，点击 **新建配置**；也可以使用 **导入 .dc** 打开已有文件。
2. 在表单中填写内容，或切换到文本视图直接修改。
3. 打开检查视图，处理提示的问题。公告配置还可以切换到预览视图查看内容。
4. 点击导出，保存 `.dc` 文件；打开多份配置时，可以选择导出当前文件或全部文件。
5. 将导出的文件放到目标实例中相应的配置位置，再在 DLC Manager 中使用。

网页中导出的文件可能进入浏览器下载目录，不会自动替换游戏实例中的原文件。请检查保存位置和文件名。

## 常见问题

**打开后类型不正确。** 在侧栏选择与文件用途相符的配置类型，再检查字段内容。

**公告预览没有显示。** 检查是否填写了公告正文或可访问的内容链接；在线内容也可能受到网络或网站访问限制。

**编辑后的配置没有在游戏中生效。** 先确认已经导出文件，并放到正确实例的对应目录。编辑器中的未导出修改不会自动应用到游戏。

需要在日常代码编辑器中编写 `.dc` 时，也可以使用 [VS Code 插件](../editor/vscode-dc-language/README.zh.md) 或 [JetBrains 插件](../editor/jetbrains-dc-plugin/README.zh.md)。
