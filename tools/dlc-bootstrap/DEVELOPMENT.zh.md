# 进度查看与问题处理

[English](DEVELOPMENT.md)

DLC Manager 会在 Forge 或 NeoForge 启动时准备必要资源。准备完成后，游戏或专用服务端会自动继续启动。配置方法见[安装与使用](README.zh.md)。

## 查看进度

默认加载界面会显示下载和安装进度。没有进度窗口时，可查看启动日志中带有 `[dlc-manager-bootstrap]` 的内容。专用服务端也通过日志显示进度。

首次启动可能需要较长时间下载文件，请等待准备完成，无需额外操作。

## 提示安装失败

必要资源无法准备完成时，启动会停止，并提示安装失败。

1. 查看启动日志，找到出错的资源及具体原因。
2. 检查该资源的 `.dc` 配置和下载地址。如果日志提示网络或文件访问问题，先解决对应问题。
3. 重新启动游戏或服务端，重试资源准备。

## 必要文件缺失

缺失的必要文件会在下次启动时自动恢复。已有目标文件会保留，不会在此准备阶段被替换。

如果同一个文件反复提示缺失，请检查对应资源配置和启动日志。

## 更新后新增了必要资源

游戏或服务端运行期间新增的必要资源，会在下次启动时准备。需要使用这些资源时，请先保存当前工作，再重新启动。

部分模组首次安装后可能还需要再次重启，请遵循这些模组提供的说明。

## 支持版本

启动时准备必要资源的功能支持 Forge 1.20.1 和 NeoForge 1.21.1，客户端与专用服务端均可使用。Fabric 版本继续使用原有的必要资源安装流程。

此功能不会在游戏运行中加载新模组。日常 DLC 管理、下载和更新用法见[主项目说明](../../README.zh.md)。
