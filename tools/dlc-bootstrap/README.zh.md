# 必要资源自动准备

[English](README.md)

DLC Manager 在 Forge 1.20.1 和 NeoForge 1.21.1 启动时自动下载并安装配置要求的必要资源。普通模组、资源包及其他文件准备完成后，游戏才会继续启动。客户端和专用服务端均支持此功能。

## 构建

在仓库根目录运行：

```sh
./gradlew build --parallel
```

请使用 `output/<版本>/` 中与 Minecraft 版本及加载器匹配的文件。资源准备过程中的常见问题见[进度查看与问题处理](DEVELOPMENT.zh.md)。

## 安装

将适合当前 Minecraft 版本和加载器的 DLC Manager 模组文件放入实例的 `mods` 文件夹，并按[主项目说明](../../README.zh.md)安装所需依赖。

此功能已包含在 DLC Manager 中，无需额外安装 Bootstrap，也无需修改启动参数。

## 使用

整合包作者先在 `config/dlc_manager/config.dc` 配置 DLC 根目录，再在各根目录的 `required` 文件夹添加必要资源的 `.dc` 配置。玩家正常启动实例即可。首次启动可能需要等待下载；之后启动会检查文件，缺失时重新安装。

- 必要资源准备完成前，请等待启动流程结束。
- 已存在的目标文件不会在此阶段被替换。
- Forge 和 NeoForge 客户端的默认加载界面会显示下载和安装进度。
- 没有进度窗口时，可查看启动日志中带有 `[dlc-manager-bootstrap]` 的内容。专用服务端也通过日志显示进度。
- 下载、配置或安装出错时，启动会停止，并显示“必要资源安装失败”。按照日志修复问题后，重新启动实例即可重试。
- 运行期间更新新增的必要资源，会在下次启动时准备。

## 适用范围

Fabric 版本继续使用原有的必要资源安装流程。需要额外启动步骤的特殊模组，首次安装后仍可能要求再次重启；请以该模组的安装说明为准。

此功能不会在游戏运行中加载新模组。日常管理、下载和更新用法见 [DLC Manager](../../README.zh.md)。
