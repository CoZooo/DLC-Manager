DLC Manager embeds the original Kotlin JVM standard library JAR without changing
its class files, package names, module descriptors or multi-release metadata.
The early Java bridge loads this archive through an isolated runtime class loader.
The Kotlin compiler, Kotlin/Native runtime, JS and Wasm distributions are not bundled.
